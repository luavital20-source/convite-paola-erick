# Fotos do convite

Coloque as imagens nesta pasta com **exatamente** estes nomes:

| Arquivo | Onde aparece | Sugestão |
|---|---|---|
| `casal.jpg` | Foto grande de abertura (tela inteira) | Foto **vertical** (retrato), pelo menos 1200×1800px |
| `local.jpg` | Foto do Pauletto Eventos | Foto **horizontal**, pelo menos 1200×800px |

Enquanto as fotos não forem enviadas, o convite mostra um fundo verde oliva
elegante no lugar delas — nada quebra.

Se preferir usar `.png`, troque a extensão também no `index.html`
(procure por `img/casal.jpg` e `img/local.jpg`).
